# Polices du rapport

Roboto (Apache License 2.0, Google) et Poppins (Apache License 2.0,
Indian Type Foundry) — téléchargées depuis les dépôts officiels
Google Fonts, versionnées ici pour que la compilation ne dépende pas
des polices installées sur la machine de chaque membre de l'équipe.

- `Roboto-Regular.ttf`, `Roboto-Bold.ttf`, `Roboto-Italic.ttf`
- `Poppins-Regular.ttf`, `Poppins-SemiBold.ttf`
