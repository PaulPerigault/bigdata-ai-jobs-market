# Matériel du sujet — non committé intentionnellement

Le sujet PDF et la trame docx originaux du professeur ne sont pas versionnés
dans ce repo (voir `.gitignore`). Raison : ce sont des documents propriétaires
du professeur, pas du matériel produit par toi — les redistribuer dans un
repo qui peut devenir public (portfolio) n'est pas souhaitable, et ce n'est
plus nécessaire : tout leur contenu utile est déjà digéré dans :

- `docs/sujet-synthese.md` — synthèse complète du PDF (contexte, architecture,
  objectifs, planning J1-J3, requêtes/KPI obligatoires, barème)
- `report/rapport.tex` — structure exacte de la trame docx (sections, tableaux
  à remplir), déjà intégrée

Si tu veux les garder en local pour toi (référence perso), place-les ici :
- `docs/sujet/Projet_BigData_IA_Version_Etudiants.pdf`
- `docs/sujet/Trame_Rapport_Projet_BigData_IA_Etudiants.docx`

Ils resteront ignorés par git (`docs/sujet/*.pdf`, `docs/sujet/*.docx` dans
`.gitignore`) — présents sur ton disque, absents du repo.
