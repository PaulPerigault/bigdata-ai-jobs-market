# Notes en cours de route

Une idée, une piste d'analyse, un problème rencontré et sa solution — tout
ce qui surgit pendant le travail sur une issue et qui ne rentre pas encore
proprement dans le rapport va ici, pas perdu dans un commentaire GitHub ou
oublié.

Convention : `docs/notes/<slug>.md`, un fichier par sujet. Pas de structure
imposée — texte libre, mais dater et signer (rôle, pas nécessairement le
nom) chaque entrée pour tracer l'origine.

Ces notes sont la matière première du rapport (`report/sections/`), pas un
substitut — une note qui mûrit devient du contenu rédigé dans la bonne
section, avec l'interprétation qui va avec.
